# K. A. Kaneriya & Associates — Website

Elegant law firm website for **K. A. Kaneriya & Associates**, Rajkot.

## Tech Stack

- **Next.js 15** (App Router)
- **React 19**
- **Tailwind CSS 4**
- **TypeScript**
- **Lucide React** (icons)
- **Unsplash** (professional law firm imagery)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build for Production

```bash
npm run build
npm start
```

## Project Structure

```
src/
├── app/           # Next.js app router (layout, page, styles)
├── components/    # Reusable UI sections
└── data/          # Site content and configuration
```

## Sections

- Hero with call-to-action
- About / Why hire us
- Client testimonials
- Main practices (Family, Revenue, Notary)
- Section 138 featured service
- Full services list
- Contact information and social links
